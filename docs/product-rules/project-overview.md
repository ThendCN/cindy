# 项目概览

> **状态**：提案实现中（PR 1：只读概览页）
> **适用范围**：桌面端本机项目的概览页及其入口
> **读取时机**：修改项目概览页、其入口按钮或任务分列规则之前

## 1. 入口

本机项目行悬停时，按钮组为「项目概览 → 更多 → 新建任务」，概览按钮位于「更多」之前。
远程项目（SSH、远程设备）不显示该按钮。点击按钮只打开概览页，不折叠或展开项目行。

## 2. 任务分列

概览页把该项目的全部任务（含置顶与已归档，归属与侧边栏项目行一致）分为四列，按以下
顺序判定，命中即停：

| 列 | 条件 |
|---|---|
| 进行中 | 任务正在运行（与侧边栏运行指示同一口径） |
| 已归档 | 任务已归档 |
| 等你处理 | 侧边栏该任务显示红点（出错、定时任务失败）或蓝点（等待确认、回答提问等） |
| 最近 | 其余任务，包括完成未读（绿点） |

- 运行优先于归档：自动任务会先恢复已归档任务再运行，正在运行的任务应可见。
- 归档优先于提醒：归档表示用户认为这件事已结束，不再催促。
- 「等你处理」与侧边栏灯语同源（`sessionLampAggregation.ts` 的 `dotToneOf`）：同一任务
  在概览页与侧边栏必须显示同一状态；不在未读集合内的提醒不计入。
- 不设「已完成」列：完成未读是内存态，重启后消失，不能作为稳定分类。
- 列内顺序与侧边栏项目内顺序一致（最近活动在前）。

## 3. 边界

- 概览页只读展示，不新增存储、IPC 或数据库迁移；不支持拖动任务改变状态。
- 概览页不得成为第二个通知 owner：不调用会触发通知或清除提醒的运行状态 hook，只读订阅。
- 暂不支持远程项目与手机端。
